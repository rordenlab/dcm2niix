# BIDS And ReproIn Reference

Use this before changing BIDS sidecars, physio output, `BidsGuess`, classification, `-f %h/%H`, `reproin.cpp`, or `tools/reproinx.py`.

## BIDS Sidecars

PET `TimeZero` and `InjectionStart` are deliberately not emitted (a derived time-zero convention would be a fabrication; PET2BIDS picks it downstream — raw PET is not validator-complete by design); local `t` still feeds `ImageDecayCorrectionTime`. PET DOES emit both raw anchors, `SeriesTime` AND `AcquisitionTime` ((0008,0032), emitted in the PET block since the two can differ for dynamic/multi-bed/subset recons and PET2BIDS consumes both); PET `AcquisitionDateTime` stays suppressed. The general non-PET `AcquisitionTime`/`AcquisitionDateTime` emitter skips PET to avoid double emission. `AcquisitionTime`/`AcquisitionDateTime` seconds use `%09.6f`, not `%02.6f`. Classic 2D Siemens (non-mosaic) `AcquisitionTime` is the earliest slice of the first volume, not instance 1 (interleaved/concatenated slices, issue 1039), making it the origin of `SliceTiming`; the earliest is by (`AcquisitionDate`, `AcquisitionTime`) so a volume spanning midnight also takes that slice's date, and a candidate more than 12 h before instance 1 is rejected as corrupt; `sliceTimingSiemens2D()` sets it after TR estimation and `checkDateTimeOrder()`, which still use per-file times. Known limitation (all time emitters, pre-existing): DICOM `TM` values are `atof`'d to a number, so reduced-precision `TM` (e.g. `"12"` = 12:00, `"1234"` = 12:34) is decoded as if it were full `HHMMSS` (→ `00:00:12`, `00:12:34`) and exact-midnight `0` is suppressed; PET AcquisitionTime keeps fractional seconds (SeriesTime int-casts them away). Real PET scanners write full `HHMMSS.frac`. MolarActivity (0018,1077) → BIDS `MolarActivity`/`MolarActivityUnits` (molar Bq/umol), NOT the mass-based `SpecificRadioactivity`. XA60 fMRI `SequenceName` falls back to `pulseSequenceName`. Siemens `MatrixCoilMode` always emits; `patMode` other than 1/2 maps to `"None"`. BIDS sidecar `dim_5: DIM_DYN` emits for SVS but is suppressed for MRSI Row/Plane/Volume. The VOI sidecar block requires both `voiThickness > 0` and `hasVoiCenter`; never fabricate `[0,0,0]`. `PulseSequenceType` `isSP` checks `SP\`, sole `SP`, and `\SP`; avoid `OSP` false positives. `ParallelReductionFactorInPlane/OutOfPlane` emit at `>= 1.0`; `PartialFourier` emits only when `< 1.0`; full Fourier (Siemens CSA `ucPhasePartialFourier=16`, `(0018,9081)=NO`) omits it on purpose: bids-validator 3.0.2 rule `MRIPartialFourier` recommends `PartialFourierDirection` whenever `PartialFourier` exists, no vendor writes `(0018,9036)` for full Fourier, so emitting `1` adds a `SIDECAR_KEY_RECOMMENDED` warning per series (tried and reverted; do not re-add). bids-specification PR #2561 (opened 2026-10-24) proposes recommending `PartialFourierDirection` only when `PartialFourier` < 1; if merged, `1` can be re-emitted. Siemens partial Fourier (CSA `ucPhasePartialFourier`, or the XA phase-line estimate; both phase-only) sets `PartialFourierDirection` `PHASE` when `(0018,9036)` is absent. `TablePosition` emits only when a vendor tag was read (`tablePos[0]` flag; GE needs `(0043,10B2)`); `[0,0,~1e-9]` in outputs <= v1.0.20260416 on GE files lacking it was uninitialized garbage, not a near-origin reading. `+0.0f` prints `-0` as `0`; no near-zero rounding by design. `PulseSequenceType` is a heuristic classification (BIDS recommended), not a rename; `(0018,9005)` PulseSequenceName is promoted to `SequenceName` only when `(0018,0024)` is absent. Siemens MP2RAGE (`lInvContrasts==2`) emits `RepetitionTimePreparation` = `(0018,0080)`/1000 (inversion-to-inversion time, s). MP2RAGE `NumberShots` = `sFastImaging.lTurboFactor`, emitted on XA only (a stuck constant 16 on VB/VE). Philips Dixon (issue 1038): each type is its own series with filename postfix `_water`/`_fat`/`_inphase`/`_outphase` (suppressed by `--terse` and by `%h`/`%H` BIDS naming) and `WATER`/`FAT`/`IN_PHASE`/`OUT_OF_PHASE` appended to sidecar `ImageType` unless already present. For BIDS naming the type is a `rec-water`/`rec-fat`/`rec-inphase`/`rec-outphase` entity: `setBids` inserts it into `BidsGuess` (so `%h`), and `reproinParseSpec` fills `spec->rec` when the protocol sets none (so `%H`); an existing `rec-` wins (so a protocol `rec-` makes the types collide again). Dixon detection (`_W_`/`_F_`/`_IP_`/`_OP_` ImageType tokens) is not vendor-gated; no false positives across the corpus. `RepetitionTimeExcitation`/TR_GRE is not emitted: echo spacing is absent from the DICOM on every platform (twix/PDF only) and is not derivable from bandwidth (identical BW gives different ES across platforms).

## Physio

Physio writer invariants: `xaPhysioWriteStreamFiles` returns false on any alloc/open/write/deflate/finalize failure and unlinks partials; OOM is `Failed`, not `Skipped`; degenerate no-sensor input is `Skipped`. The physio TSV completeness guard keeps the row index outside the loop and fails if `i != nSamples`. The physio raster rejects non-finite timing and bounds `expD` before the int cast; non-finite signal values print BIDS `n/a`. CMRR/XA volume tics use `strtol` plus a consumed-start check; do not use `atol` or strict full-token matching. cJSON required-key attach is post-verified for `PhysioType`, `Columns`, `SamplingFrequency`, `StartTime`; peak-column `Description` is best-effort only. Siemens/XA/CMRR physio TSV columns are `[signal, trigger, label_trigger]` when firmware peaks exist; the EXT peak is `external_trigger_peak`; the C-side does not emit physio `TaskName` (reproinx backfills it). The CMRR `*_TRIGGER` sentinel `VALUE=2048` is dropped from the waveform; do not leak it like bidsphysio. `CMRRMeasurementUUID` is authoritative only from a CMRR-gated Phoenix `sWipMemBlock.tFree` leading canonical UUID or an exact embedded CMRR `UUID =` header; reject nil/malformed values and omit on conflicts. Because it can provide a persistent link to source DICOM data, the key is emitted only under `-ba n`. Suppressing the key is not enough on its own: for CMRR sequences the same UUID leads `sWipMemBlock.tFree`, so `-ba y` also redacts it from `WipMemBlock` via `cmrrRedactLeadingUuid()`. `-ba o` keeps that copy, consistent with the `SeriesInstanceUID`/`StudyInstanceUID` it deliberately retains.

## Classification

`MRWeightingGuess()` is the shared classifier; `isVariableFlipAngle` forces Unknown on the physics fallback. Its spin-echo path returns T1w for short TE + short TR (`<= 1 s`), else T2w (TE `>= 45 ms`) / PDw. Conventional Siemens spin echo (`\se` in seqDetails or `*se2d` pulseSequenceName — excludes `tse`/`epse`/`ep2d_se`) classifies as anat via this path. `setBidsFromAcquisitionContrast()` is strictly additive: bare `AC=PERFUSION` stays Unknown, and `AC=DIFFUSION` requires DTI and sets `isDiffusion`. Siemens/Philips/GE ASL classifiers must not use bare `AC=PERFUSION`; require vendor-positive ASL signals. SPACE/FLAIR detection includes `\space` and `pulseSequenceName`; PACE is anchored on `_pace`. Siemens VIBE/SWI/MPRAGE label order is intentional; SWI is a `_SWI` `strstr` substring test on ImageType (not a bounded token — no `_SWIRL`-type token occurs in practice). The vendor-agnostic DWI derivative fallback maps `_FA/_ADC/_colFA/_expADC/_trace/_S0map` to `dwi` and tensor to `derived`; do not override `discard`. Siemens derived diffusion maps and all-zero IOP non-spatial images go to `discard/derivedDWI` or `discard/nonspatial`; raw DWI is `ORIGINAL`. reproinx moves `discard`/`derived` to `derivatives/scanner/`. CT is emitted by C-side `%h` as lowercase `ct/_ct` but is intentionally not rescued by reproinx until BEP-024 is ratified.

Filename tokens: `-f %v` is full vendor, `%m` is the abbreviation; `%h` is legacy hazardous BIDS, `%H` is ReproIn. The `%h/%H` experimental-naming warning fires once per process.

## ReproIn

`reproinx.py` runs dcm2niix with `-ba o` unless `--anonymize`; `-ba y/n/o` map to strip dates+PII / keep both / strip PII only, and the omit/anonymize flags are independent. `--shift-dates` runs last, shifts sidecars and `_scans.tsv` to 1925 per subject, preserves intervals, discovers and shifts every date source (sidecar `AcquisitionDateTime`, `AcquisitionDate`+`AcquisitionTime`, and `_scans.tsv` `acq_time`), shifts retained derivatives, deletes provenance `.tsv` and `.bak`, warns on timestamp `ses-YYYYMMDD...` rather than renaming, and fails closed. It also covers **subjectless** output (load-bearing, issue audit 2026-07-07): `--shift-dates` runs via `_run_shift_dates` even when no `sub-*` tree exists (an all-`Unknown/` study — CT-only, or wholly unrescued — would otherwise ship real dates + provenance at exit 0), and `_shift_dates`' post-subject sweep covers every date-bearing file the per-subject walk misses (root-level `Unknown/*.json`, derivative sidecars, and any `*_scans.tsv`), per-file anchored. Do not re-add an early `return` before the shift pass in `_post_process`. `%H` provenance TSV is written once per series only when the filename contains literal `%H`; a stale schema rotates to `.bak`. `BidsGuess` consumption is path-hardened by `_BIDS_DATATYPES` and `[A-Za-z0-9_-]*`; `out_root` is assumed single-user trusted. `mrs` is allowed in reproinx; `ct` is intentionally not (until BEP-024).

`reproinParseSpec` (one-pass `%H`): sub/ses labels (PatientID, `-bi`, `-bv`) and entity values are scrubbed to `[A-Za-z0-9]` by `reproinSanitizeLabel`; barewords (no `-`, except heudiconv `run+`/`run=`) are scrubbed and appended to `acq`; text before an explicit `<datatype>-<suffix>` token is ignored with a warning (`spec->hasPrefix`), but a bare datatype must lead. `reproinKnownDatatype` omits `perf` (known gap). `ses-{date}` is the one value the scrub keeps verbatim; `reproinResolveSession` expands it (and `DATE`) to StudyDate, then scrubs; no StudyDate omits the `ses-` segment. Legacy `%h` never expands `{date}`. A non-ReproIn ProtocolName goes to `Unknown/` with a warning naming SeriesNumber + SeriesInstanceUID (`(anonymized)` under `-ba y`). `_SBRef_Pha` (XA phase) is also `sbref`. `inv` is a slotted entity (`spec->inv`), emitted after `echo`. MP2RAGE (`anat-MP2RAGE`) is split by content: `inv-N` and `UNIT1` from BidsGuess (BidsGuess `inv-` overrides the protocol's: one protocol yields INV1/INV2/UNI, so a protocol value would collide; UNIT1 clears `inv`; without BidsGuess the protocol `inv-` stands), UNI-DEN (same ImageType, only SeriesDescription differs) → `rec-denoised` (`desc-` is derivatives-only), `_ND` ImageTypeText → `ND` appended to `acq`; UNIT1 is kept raw despite DERIVED ImageType. OpenRecon: FRISGO as an ImageTypeText token at index >= 4 (the filtered copy; the raw passthrough has it only at index 3) → `rec-frisgo` in `derivatives/scanner`; SynthSeg (ImageTypeText `SYNTHSEG`, SeriesDescription `*_<app>_OR`) non-`original` apps → `derivatives/scanner` `desc-<app>`, `original` stays raw. The app name is scanned backward from `_OR` over lowercase tokens, stopping at an entity token (contains `-`, e.g. `acq-x`) and never reaching into a ProtocolName prefix of SeriesDescription; a trailing `_original` before `_OR` marks the raw passthrough. `reproinIsDerived` matches `_FA`/`_ADC`/`_TRACE` only as a token ending at a non-alphanumeric (`_FATSAT` BOLD is raw).

## Cross-Series Passes

Trailing-suffix protocols without a leading datatype are noncanonical and land in `Unknown/`; rescue recovers from `ProtocolName`. Study-scoped `ses-<X>` from protocol beats the StudyDate/Time timestamp fallback; conflicting labels block recovery for that StudyInstanceUID. `discard`/`derived` in `Unknown/` moves to `derivatives/scanner/Unknown/`, not raw `Unknown/`; empty BidsGuess stays Unknown. `BidsGuess` `_run-<SeriesNumber>` is a raw acquisition counter; strip it unless the protocol has an explicit numeric run, and insert run in canonical entity order. `_strip_orphan_runs` removes non-disambiguating `_run-NN` unless an operator protocol run exists. `_strip_sbref_gradients` removes `.bval`/`.bvec` from `*_sbref` (a single-band reference belongs to a diffusion series, so dcm2niix writes gradients, but BIDS does not associate them with `_sbref`); it runs post-propagation (Pass 2), after the tree is consolidated into `ses-`.

`_reclassify_session` runs first; short single-echo EPI with a long EPI sibling becomes `fmap/..._dir-<L>_epi`; multi-echo is skipped because `_epi` forbids `echo`. `_to_fmap_epi_stem` drops `task-`, canonicalizes fmap entities, and prefers existing anatomical `dir-AP/PA` over voxel-axis labels. R2 reclassifies co-planar `anat/..._T2w` to `_inplaneT2`. Half-session consolidation folds strays into the single existing session only for recognized BIDS datatype dirs; curated folders stay put.

`_move_stem_files` is the all-or-nothing family move primitive (preflight plus best-effort rollback); reuse it for sidecar families. `_sbref` is an fmap target but must mirror its bold sibling's `B0FieldSource` selection, including `None`. An fmap group whose `_epi` files all share one `PhaseEncodingDirection` (e.g. FOV rotated 180° instead of reversed PE) is dropped with a warning (`_is_same_polarity_epi_group`); heudiconv keeps it. On reruns its stale `B0FieldIdentifier` and matching `B0FieldSource` references are removed; unrelated sources are kept. `_backfill_tasknames` serves physio and sbref sidecars; a dataset-level `task-X_bold.json` `TaskName` is not inherited. `_rescue_unknown_physio` pairs by `(task, run)` from filename, deliberately excludes session, resolves subject from the sanitized provenance `OutputStem`, requires exactly one subject and one BOLD, and moves atomically. `_rescue_physio_recordings` returns skipped counts; `_drop_derivatives` must preserve roots with skipped physio unless strict mode already raised. `_resolve_part_entities` fixes multi-echo BOLD+phase: mag/phase series collide onto one `%H` stem (dcm2niix appends `a`/`b` and can misname a phase SBRef `_bold`), so it renames the family to `_part-<mag|phase>_<bold|sbref>` — `part` from BidsGuess's explicit `_part-` (fallback ImageType, so CSA `isHasPhase` without public ImageType still resolves), suffix from BidsGuess; group renames are all-or-nothing (rollback + re-raise). A protocol repeated as several mag/phase acquisitions is paired by `AcquisitionTime` into `run-NN` (`_part_runs`; unpairable groups are skipped). An sbref/noRF group takes the run of the nearest-in-time BOLD acquisition (same prefix), so a single SBRef beside a multi-run BOLD gets that BOLD's run; two acquisitions claiming one BOLD run, or missing/unparsable times, skip the group. It also adds `Units: "arbitrary"` to the resolved Siemens phase sidecars (scanner-scaled, not radians; never overwrites existing) since BIDS requires phase Units; `_siemens_phase_units` sweeps every datatype's `*_part-phase_*.json` (e.g. ep3d QSM `anat/..._part-phase_T2starw`). `_walk_sessions` yields the subject dir as well as its `ses-*` when session-less datatype dirs sit beside them (a rescued `Unknown/` series can get `ses-<date>` before backfill), else those dirs skip every per-session pass; hidden dirs (`.ipynb_checkpoints`) are ignored. `_emit_task_bold_jsons` deletes generated root `task-*_bold.json` stubs with no matching bold data (dcm2niix writes one for PhysioLog/`SBRef_PMU`-only func series → `SIDECAR_WITHOUT_DATAFILE`); curated files are kept with a warning. `_emit_events_tsv` strips `_echo-` and `_part-` so one run-level `_events.tsv` is shared across echoes/parts.

Siemens RF-off (noise) volumes (issue #1025) are split C-side, not in reproinx: `(0021,1175)` ImageTypeText carries a `NOISE` token per frame (top-level `ImageType` is identical for noise and imaging volumes, so it cannot be used; detection matches `NOISE` as a full `_`-delimited token in any position, not a bare substring), `d.isNoRF` splits the series in `isSameSet` exactly like `isDerived`. The BIDS suffix is `_noRF` (a full suffix, NOT `_bold_noRF` — the validator rejects two stacked suffixes; disambiguate colliding noRF suffixes with the `mod-` entity instead). Three output surfaces emit it independently, because `%H` disables the filename postfix mechanism: the plain-filename postfix (`_noRF` beside `_ph`/`_real`), `setBidsSiemens`' BidsGuess (`func/_noRF`), and — for canonical `-f %H` ReproIn protocols — `reproinParseSpec` forcing `spec->suffix="noRF"` (func-gated) so a noise volume does not collide onto the protocol's `_bold` stem. reproinx needs no rescue pass — BidsGuess carries it; `_resolve_part_entities` includes `noRF` so mag/phase noise volumes get `_part-` — but `_is_target_for_fmaps` excludes `_noRF` (nothing is imaged, so there is no distortion to correct and it must not enter a fieldmap's `IntendedFor`), and `_emit_events_tsv` already skips it by globbing `*_bold.nii*`.

Multi-delay pCASL (Siemens XA `tgse_pcasl_loft`, LOFT/Danny Wang) → BIDS ASL. XA image DICOMs expose no per-volume label/control/M0 marker, so the `tgse_pcasl_loft` handler in `nii_dicom_batch.cpp` reads the CSA WIP block — PLDs (`sWipMemBlock.alFree[1..5]`), per-PLD repeat counts (`alFree[8..12]`), labeling duration (`adFree[2]`) — and emits `ArterialSpinLabelingType`, `LabelingDuration`, `TotalAcquiredPairs`, `M0Type`, `BackgroundSuppression`, and the per-volume `PostLabelingDelay` array. Volume order is `[M0, dummy(s), label/control pairs]`; BIDS has no dummy `volume_type`, so the C side emits `ReproinxDropVolumes` and reproinx's `_emit_aslcontext` drops those volumes (NIfTI byte surgery), trims `PostLabelingDelay`, and writes `_aslcontext.tsv`. `tools/pcasl_process_bids.py` is a standalone quick-look CBF tool, not part of the pipeline.

## Behaviour Changes (v1.0.20261024)

- Siemens partial Fourier (CSA `ucPhasePartialFourier`, or the XA phase-line estimate) emits `PartialFourierDirection` `PHASE` when `(0018,9036)` is absent.
- `TablePosition` prints `0`, not `-0`.

## Behaviour Changes (v1.0.20261021)

- Philips Dixon outputs get `rec-water`/`rec-fat`/`rec-inphase`/`rec-outphase` in `BidsGuess` and `%h`/`%H` names (issue 1038).
- T1-weighted Siemens SPACE (short TE/TR) is `anat`/`T1w`, not `T2w` or `func`/`bold`.
- `NumberOfKSpaceTrajectories` (0018,9093) is written only for MR spectroscopy.
- `-n -2` writes `<outdir>/dcm2niix_series.json` (series list, no conversion); `-n -1` no longer deletes (`-w 1`) or creates (`%h`) files.
- Compressed enhanced (multi-frame) DICOM converts like the uncompressed file: Dimension Index frame order and per-frame scaling were skipped for JPEG-LS/JPEG 2000/RLE, and 4D JPEG lossless decoded wrongly or crashed.
- RLE RGB with PlanarConfiguration 1 is no longer scrambled.

## Behaviour Changes (v1.0.20261011)

- `reproinSanitizeLabel` is alphanumeric-only and also feeds legacy `%h` sub/ses (`-bi 01_pre` → `01pre`).
- Barewords fold into `acq`; the last is the suffix when none is given (`anat_mprage_sag` → `_acq-mprage_sag`).
- Text before `<datatype>-<suffix>` (e.g. `PA_func-bold…`) now parses, with a warning.
- `run-+` (with dash) is silently dropped; heudiconv `run+`/`run=` (no dash) still pass through.
- Under `-ba y` ReproIn warnings print `(anonymized)` instead of SeriesInstanceUID.
- `ImageComments` is kept under every `-ba` level (default `-ba y`): downstream tools read it, e.g. OpenRecon filter notes.
