# BIDS And ReproIn Reference

Use this before changing BIDS sidecars, physio output, `BidsGuess`, classification, `-f %h/%H`, `reproin.cpp`, or `tools/reproinx.py`.

## BIDS Sidecars

PET `TimeZero` and `InjectionStart` are deliberately not emitted (a derived time-zero convention would be a fabrication; PET2BIDS picks it downstream — raw PET is not validator-complete by design); local `t` still feeds `ImageDecayCorrectionTime`. PET DOES emit both raw anchors, `SeriesTime` AND `AcquisitionTime` ((0008,0032), emitted in the PET block since the two can differ for dynamic/multi-bed/subset recons and PET2BIDS consumes both); PET `AcquisitionDateTime` stays suppressed. The general non-PET `AcquisitionTime`/`AcquisitionDateTime` emitter skips PET to avoid double emission. `AcquisitionTime`/`AcquisitionDateTime` seconds use `%09.6f`, not `%02.6f`. Known limitation (all time emitters, pre-existing): DICOM `TM` values are `atof`'d to a number, so reduced-precision `TM` (e.g. `"12"` = 12:00, `"1234"` = 12:34) is decoded as if it were full `HHMMSS` (→ `00:00:12`, `00:12:34`) and exact-midnight `0` is suppressed; PET AcquisitionTime keeps fractional seconds (SeriesTime int-casts them away). Real PET scanners write full `HHMMSS.frac`. MolarActivity (0018,1077) → BIDS `MolarActivity`/`MolarActivityUnits` (molar Bq/umol), NOT the mass-based `SpecificRadioactivity`. XA60 fMRI `SequenceName` falls back to `pulseSequenceName`. Siemens `MatrixCoilMode` always emits; `patMode` other than 1/2 maps to `"None"`. BIDS sidecar `dim_5: DIM_DYN` emits for SVS but is suppressed for MRSI Row/Plane/Volume. The VOI sidecar block requires both `voiThickness > 0` and `hasVoiCenter`; never fabricate `[0,0,0]`. `PulseSequenceType` `isSP` checks `SP\`, sole `SP`, and `\SP`; avoid `OSP` false positives. `ParallelReductionFactorInPlane/OutOfPlane` emit at `>= 1.0`; `PartialFourier` emits only when `< 1.0`.

## Physio

Physio writer invariants: `xaPhysioWriteStreamFiles` returns false on any alloc/open/write/deflate/finalize failure and unlinks partials; OOM is `Failed`, not `Skipped`; degenerate no-sensor input is `Skipped`. The physio TSV completeness guard keeps the row index outside the loop and fails if `i != nSamples`. The physio raster rejects non-finite timing and bounds `expD` before the int cast; non-finite signal values print BIDS `n/a`. CMRR/XA volume tics use `strtol` plus a consumed-start check; do not use `atol` or strict full-token matching. cJSON required-key attach is post-verified for `PhysioType`, `Columns`, `SamplingFrequency`, `StartTime`; peak-column `Description` is best-effort only. Siemens/XA/CMRR physio TSV columns are `[signal, trigger, label_trigger]` when firmware peaks exist; the EXT peak is `external_trigger_peak`; the C-side does not emit physio `TaskName` (reproinx backfills it). The CMRR `*_TRIGGER` sentinel `VALUE=2048` is dropped from the waveform; do not leak it like bidsphysio.

## Classification

`MRWeightingGuess()` is the shared classifier; `isVariableFlipAngle` forces Unknown on the physics fallback. `setBidsFromAcquisitionContrast()` is strictly additive: bare `AC=PERFUSION` stays Unknown, and `AC=DIFFUSION` requires DTI and sets `isDiffusion`. Siemens/Philips/GE ASL classifiers must not use bare `AC=PERFUSION`; require vendor-positive ASL signals. SPACE/FLAIR detection includes `\space` and `pulseSequenceName`; PACE is anchored on `_pace`. Siemens VIBE/SWI/MPRAGE label order is intentional; SWI is a `_SWI` `strstr` substring test on ImageType (not a bounded token — no `_SWIRL`-type token occurs in practice). The vendor-agnostic DWI derivative fallback maps `_FA/_ADC/_colFA/_expADC/_trace/_S0map` to `dwi` and tensor to `derived`; do not override `discard`. Siemens derived diffusion maps and all-zero IOP non-spatial images go to `discard/derivedDWI` or `discard/nonspatial`; raw DWI is `ORIGINAL`. reproinx moves `discard`/`derived` to `derivatives/scanner/`. CT is emitted by C-side `%h` as lowercase `ct/_ct` but is intentionally not rescued by reproinx until BEP-024 is ratified.

Filename tokens: `-f %v` is full vendor, `%m` is the abbreviation; `%h` is legacy hazardous BIDS, `%H` is ReproIn. The `%h/%H` experimental-naming warning fires once per process.

## ReproIn

`reproinx.py` runs dcm2niix with `-ba o` unless `--anonymize`; `-ba y/n/o` map to strip dates+PII / keep both / strip PII only, and the omit/anonymize flags are independent. `--shift-dates` runs last, shifts sidecars and `_scans.tsv` to 1925 per subject, preserves intervals, discovers and shifts every date source (sidecar `AcquisitionDateTime`, `AcquisitionDate`+`AcquisitionTime`, and `_scans.tsv` `acq_time`), shifts retained derivatives, deletes provenance `.tsv` and `.bak`, warns on timestamp `ses-YYYYMMDD...` rather than renaming, and fails closed. It also covers **subjectless** output (load-bearing, issue audit 2026-07-07): `--shift-dates` runs via `_run_shift_dates` even when no `sub-*` tree exists (an all-`Unknown/` study — CT-only, or wholly unrescued — would otherwise ship real dates + provenance at exit 0), and `_shift_dates`' post-subject sweep covers every date-bearing file the per-subject walk misses (root-level `Unknown/*.json`, derivative sidecars, and any `*_scans.tsv`), per-file anchored. Do not re-add an early `return` before the shift pass in `_post_process`. `%H` provenance TSV is written once per series only when the filename contains literal `%H`; a stale schema rotates to `.bak`. `BidsGuess` consumption is path-hardened by `_BIDS_DATATYPES` and `[A-Za-z0-9_-]*`; `out_root` is assumed single-user trusted. `mrs` is allowed in reproinx; `ct` is intentionally not (until BEP-024).

## Cross-Series Passes

Trailing-suffix protocols without a leading datatype are noncanonical and land in `Unknown/`; rescue recovers from `ProtocolName`. Study-scoped `ses-<X>` from protocol beats the StudyDate/Time timestamp fallback; conflicting labels block recovery for that StudyInstanceUID. `discard`/`derived` in `Unknown/` moves to `derivatives/scanner/Unknown/`, not raw `Unknown/`; empty BidsGuess stays Unknown. `BidsGuess` `_run-<SeriesNumber>` is a raw acquisition counter; strip it unless the protocol has an explicit numeric run, and insert run in canonical entity order. `_strip_orphan_runs` removes non-disambiguating `_run-NN` unless an operator protocol run exists.

`_reclassify_session` runs first; short single-echo EPI with a long EPI sibling becomes `fmap/..._dir-<L>_epi`; multi-echo is skipped because `_epi` forbids `echo`. `_to_fmap_epi_stem` drops `task-`, canonicalizes fmap entities, and prefers existing anatomical `dir-AP/PA` over voxel-axis labels. R2 reclassifies co-planar `anat/..._T2w` to `_inplaneT2`. Half-session consolidation folds strays into the single existing session only for recognized BIDS datatype dirs; curated folders stay put.

`_move_stem_files` is the all-or-nothing family move primitive (preflight plus best-effort rollback); reuse it for sidecar families. `_sbref` is an fmap target but must mirror its bold sibling's `B0FieldSource` selection, including `None`. `_backfill_tasknames` serves physio and sbref sidecars; a dataset-level `task-X_bold.json` `TaskName` is not inherited. `_rescue_unknown_physio` pairs by `(task, run)` from filename, deliberately excludes session, resolves subject from the sanitized provenance `OutputStem`, requires exactly one subject and one BOLD, and moves atomically. `_rescue_physio_recordings` returns skipped counts; `_drop_derivatives` must preserve roots with skipped physio unless strict mode already raised. `_resolve_part_entities` fixes multi-echo BOLD+phase: mag/phase series collide onto one `%H` stem (dcm2niix appends `a`/`b` and can misname a phase SBRef `_bold`), so it renames the family to `_part-<mag|phase>_<bold|sbref>` — `part` from BidsGuess's explicit `_part-` (fallback ImageType, so CSA `isHasPhase` without public ImageType still resolves), suffix from BidsGuess; group renames are all-or-nothing (rollback + re-raise). It also adds `Units: "arbitrary"` to the resolved Siemens phase sidecars (scanner-scaled, not radians; never overwrites existing) since BIDS requires phase Units. `_emit_events_tsv` strips `_echo-` and `_part-` so one run-level `_events.tsv` is shared across echoes/parts.
